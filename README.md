# مداري | MADARI – International Business Linkage

موقع مداري للربط التجاري بين الشركات المحلية والدولية — madari.com.sa

## الهيكل
- `*.html` — الصفحات العربية (الأساسية، RTL)
- `en/*.html` — النسخة الإنجليزية
- `assets/css/style.css` — التصميم (الألوان: أزرق ملكي + ذهبي)
- `assets/js/main.js` — الهيدر والفوتر وبيانات التواصل (تُعدَّل من مكان واحد)
- `assets/js/geo.js` + `land.js` — الكرة الأرضية والخرائط والشرائط المتحركة
- `send.php` — استقبال نماذج طلب الخدمة وإرسالها إلى info@madari.com.sa
- `sitemap.xml` / `robots.txt` — تهيئة محركات البحث

## النشر
موقع ثابت (HTML/CSS/JS) + PHP لنموذج التواصل. ينشر مباشرة على Hostinger من فرع `main` إلى `public_html`.
